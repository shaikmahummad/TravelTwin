# Mobile app

This is the React Native + Expo home for the tourist experience. The current
root Vite app is the SIH showcase prototype; this folder is the clean handoff
point for production mobile screens.

```bash
npm install
npx expo start
```

Recommended screens: onboarding, Traveller Twin setup, home, planner, live
guide, smart reroute, culture layer, explore, chat guide, and safety/offline.
